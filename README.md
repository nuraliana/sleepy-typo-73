## The entry

One line, one slip, one ruined work reputation: a routine "sorry, I was on
mute" to the boss comes out as "sorry, I was on nude", and suddenly the
whole team believes I sit through meetings with no clothes on. The swap is a
single letter (m to n, keys right next to each other), the wrong word could
not be more out of place in a work chat, and the fallout writes itself.

Run `python3 main.py` to write the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).

A single mistyped letter flips a polite apology into an accidental confession, and the joke lands because everyone has almost sent exactly that kind of message.
Instead of excusing a silent microphone, the text invents a far stranger meeting habit, leaving the sender to explain something nobody should ever have to explain at work.
